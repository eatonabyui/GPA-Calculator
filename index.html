How to use this calculator

Enter the current cumulative GPA and GPA Credits from the same academic-history report or transcript. Quality Points are a separate field and should not be entered as credits.

For a retake, select “Yes” and enter the previous attempt. The calculator removes the previous attempt and applies the latest attempt. If a course is retaken again, keep only the latest attempt for that course lineage.

The calculator uses the supplied scale: A 4.0, A− 3.7, B+ 3.4, B 3.0, B− 2.7, C+ 2.4, C 2.0, C− 1.7, D+ 1.4, D 1.0, D− 0.7, F 0.0, and UW 0.0.
